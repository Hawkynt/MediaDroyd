# mpv-prescalers (vendored)

Two of Bin Jin's NNEDI3 prescalers for mpv, copied verbatim from <https://github.com/bjin/mpv-prescalers> at commit
`b3f0a59d68f33b7162051ea5970a5169558f0ea2`: `nnedi3-nns16-win8x4.hook` and `nnedi3-nns32-win8x4.hook` (tritical's
NNEDI3 weights, written out as GLSL). LGPL-3.0-or-later, `LICENSE.txt` beside them. Not restyled, so the next
upstream version applies cleanly; `:core:player` carries this folder as resources (`Prescalers`).
